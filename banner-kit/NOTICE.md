# Banner kit provenance and font notices

Imported from the user-provided `GitHub_Repository_Banners.zip`, created with Claude Design, on 2026-10-29. The original kit README is retained. The generator escapes embedded CSS for valid SVG/XML; its styles and drawing logic are unchanged. The fonts CSS has been supplemented with upstream copyright and license notices so every generated SVG carries them alongside its embedded fonts.
