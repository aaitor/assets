# Contributing

Thanks for helping improve this project. Use [Issues](https://github.com/aaitor/assets/issues) for reproducible bugs, questions, and feature proposals. Discuss large changes before implementing them.

1. Fork and clone the repository; create a focused branch.
2. Follow the existing style and update relevant documentation.
3. Run `python3 scripts/check.py` from the repository root. Generated projects should also run their documented application checks.
4. Open a pull request explaining the problem, resulting behavior, and how you verified it. Include a screenshot for visual changes.

Contributions are provided under this repository's license. Submit only material you have the right to contribute. Follow the [code of conduct](CODE_OF_CONDUCT.md). Report security issues privately using [SECURITY.md](SECURITY.md). Response times depend on maintainer availability.
